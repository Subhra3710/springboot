#what is @SpringBootApplication?
it is the combination of three annotations:
 1. @SpringBootConfiguration- it marks the class as a source of beans.
 2. @EnableAutoConfiguration- it automatically configure the project based on the dependencies available.
 3. @ComponentsScan-It scans the packages to find the beans and register them inside spring container.

beans-simple java objects which are managed by SpringContainer
SpringContainer will provide and destroy the object
		- it is basically a wrapper around JVM
		-the job of SpringContainer is it scans for beans and register the beans in the memory area
		- manage the life cycle of beans.
		-it performs dependency injection.
		-it manage the resources
		-also called IoC Container(Inversion of Control)
		-Implementation: BeanFactory(Interface)(Old Container)
		-ApplicationContext(New Container) 

There 3 ways to create beans:
1.using xml files(Old way-x)
2.using stereotype annotations(Java based annotation)
	-@Component
	-@Controller
	-@RestController
	-@Service
	-@Repository
3.Using configuration class: //above class
	-@Configuration-It mark the class a source of bean
	-@Bean-it tells the SpringConatiner to build a bean
